## ✨ Features

- 📍 **Precise Real-Time Geolocation & Proximity Autocomplete**: Automatic pickup location lock to the passenger's exact GPS coordinates with zero offset.
- 🛵 **10 Multi-Modal Vehicle Options**: From Rapid Scooty to EV Elite, Auto, Pink Prime, and Ambulance Assist with real dynamic Mapbox ETA and distance computation.
- 🗺️ **Full Native Mapbox 3D Routing**: Real driving route navigation with custom departure/destination pins, step-by-step navigation, and animated live tracking.
- 🛡️ **Comprehensive Safety Ecosystem**: Emergency SOS button, OTP ride start verification, real-time trip route sharing, 24/7 Safety Desk integration.
- 📋 **Trip Details & History**: Complete post-trip insights with verified Captain profile, fare breakdown, ratings, and instant support escalation.
- 💳 **Flexible Payment Gateway**: Cash, SheRide Wallet, UPI, and dynamic discount coupons/offers.

## 🚀 Getting Started

### Prerequisites
- Flutter SDK `^3.6.0`
- Android Studio / VS Code
- Android Device or Emulator (API level 24+)

### Installation

```bash
# Clone the repository
git clone https://github.com/pavanstarkin-tech/sheride-user.git

# Navigate to directory
cd sheride-user

# Install dependencies
flutter pub get

# Run on connected device
flutter run
```

## 📦 Tech Stack
- **Framework**: Flutter (Dart 3.6+)
- **Map & Routing**: Mapbox Maps Flutter SDK + Mapbox Driving API
- **Backend & Database**: Firebase Realtime Database + Hostinger REST API
- **State & Architecture**: Clean feature-first architecture with GoRouter navigation
